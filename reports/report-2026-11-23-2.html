01요약

  • 직업 운전자가 처방전·약봉투를 찍으면 운전 관련 주의사항(졸음, 어지러움, 시야 이상)을 식약처 공식 자료 근거로 바로 보여주는 서비스입니다.
  • 기능 요구사항 63건 중 P0(MVP 필수) 33건입니다. OCR, 주의문구 탐지, 근거 기반 가이드, 챗봇, 안전 제한이 핵심입니다.
  • 운전 가능 여부를 확정하지 않고, 진단·처방 변경도 하지 않습니다. 정보가 없으면 “확인 불가”로 표시합니다.
  • 데이터 11종 중 확보된 것은 e약은요와 허가정보 2종뿐입니다. OCR 정답 라벨과 평가 데이터는 아직 없습니다.
  • 개발 담당자와 일정은 아직 정해지지 않았고, 팀 확정이 필요한 항목이 16개 남아 있습니다.

07의료 안전성과 비기능 요구사항

의료 안전성 (SAF)

  • 임의 복용 중단 권고 금지 · 처방 변경 요구 응답 제한
  • 운전 가능 여부 확정 금지 · 주의정보와 의료진 확인 안내
  • 근거 없는 안전 판정 금지 · “확인 불가” 표시
  • OCR 오류로 잘못된 매칭 방지 · 사용자 확인, 불확실 매칭 차단
  • 공식 주의정보 왜곡 방지 · 원문과 생성 안내 비교
  • 운전 중 사용 위험 방지 · 정차 후 이용 안내

비기능 P0 (9건)

  • 정확성 · 매칭 오류 최소화
  • 신뢰성 · 공식 자료 근거
  • 보안 · API 키·사용자 정보 비노출
  • 개인정보 · 수집·보관·삭제 정책
  • 예외 처리 · OCR·API·LLM 실패 안내
  • 사용성 · 주의정보 바로 확인
  • 정보 정확성 · 투여량·횟수·단위 보존
  • 개인정보 보호 · 필요 범위만 처리
  • 안전성 · 음성 기능이 운전 중 사용을 조장하지 않음

P1 6건: 성능 측정, 접근성, 모듈 분리, 데이터 최신성, 카드뉴스 편의성, 음성 인식 정확도.

10문서 점검 이슈

ID 중복FR-040~045가 두 번 쓰였습니다. 3.7 복용법(FR-040~044)·상담 질문지(FR-045)와 8쪽 “요구사항 추가 후보지”(FR-040~045)가 같은 번호입니다. 추가 후보 6건을 FR-058~063으로 바꾸는 것을 제안합니다. 이 보고서에서는 “추가”로 구분했습니다.
번호3.7 절 번호가 세 번 나옵니다. 복용법 가이드, 상담 질문지, 추가 후보지 모두 3.7이고, 음성 조작은 3.8입니다.
누락FR-001~007(업로드·OCR)에 우선순위가 없습니다. 1차 개발 목록에는 업로드·OCR이 필수로, 이미지 품질 안내(FR-007)는 2차로 들어 있어 P0/P1 표기가 필요합니다.
불일치음성 안내 기준이 섞여 있습니다. FR-031 음성 안내는 P2, FR-054 음성 안내 출력은 P1, 개발 단계에서는 TTS가 3차입니다.
일정담당자와 일정이 없습니다. 확정 필요 사항으로만 남아 있어 이 보고서에는 일정 화면을 넣지 않았습니다.
