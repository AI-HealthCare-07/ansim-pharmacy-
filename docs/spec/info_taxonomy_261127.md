# 안심약국 정보 분류와 출처 근거 기준 (2026-11-27)

의약품안전나라의 정보 분류(docs/ref/nedrug_menu/ 캡처)와 약사법 시행규칙 제15조의6(복약지도서 6항목)을 기준으로,
안심약국이 약마다 제공할 정보의 범위·출처·표시 규칙을 정한다. 이 서비스는 의약품안전나라를 대체하지 않고,
OCR로 확인한 약에 해당하는 공식 정보를 같은 분류로 모아 쉬운 말로 보여 준다. 최종 확인은 약사.

## 4. 화면 규칙
1. 항목마다 근거가 있으면 본문과 함께 "출처: 기관·자료명·기준일"을 표시한다.
2. 근거 데이터가 없으면 비워 두지 않고 "확인할 수 없어요"를 표시한다. 추정·생성·이름 유사도 보충 금지.
3. 안전을 단정하는 표현 금지("DUR 0건 = 안전"이 아님). 급여 정보가 없으면 "확인할 수 없어요(비급여라는 뜻 아님)".
4. 각 화면에 의약품안전나라 원문 링크를 두어 출처로 안내하고, 공식 사이트로 오인되지 않게 한다.
5. 모든 안내는 약사 최종 확인을 전제로 한다(복약지도의 법적 주체는 약사: 약사법 제24조제4항).
6. 진단·처방·용량 변경·복용 중단에 해당하는 질문은 안내하지 않고, 처방한 의사에게 확인하도록 한다.

## 5. 범위 밖
임상시험, 약물유전정보, 바이오·첨단바이오의약품, 화장품·첨가제, GMP·특허, 공급중단·품목갱신, 낱알식별(알약 사진 식별 기능이 범위일 때만 재검토).

## 6. 기준일 모델 (처방일·조제일과 자료 시점)
- 저장: 처방일(`prescribed_date`, 처방전 발급일)과 조제일(`visit_date`/`dispensed_date`)을 따로 저장한다. OCR이 못 읽으면 비워 두고 사용자가 확인한다.
- 기준: 처방전 사용기간 확인은 처방일, 복약지도 규정은 조제일.
- 법령: 시행일 구간별 판을 보관하고 조제일에 해당하는 판을 적용한다(법제처 연혁). 복약지도서 6항목은 2026.11.18 개정 판.
- 허가사항: **수집일 기준 이력 저장을 2026-11-27부터 적용**(medicine_permit_detail_history, 변경된 판만 추가). 과거 재현은 이 날짜 이후부터만 가능하다.
- DUR·급여: 과거 시점 자료가 없으므로 "현재 기준 자료"로 표시하고 조제일 당시와 같은지는 확인할 수 없다고 표시한다.
- 오래된 처방전: 검색·조회는 허용, 현재 복약 안내로는 쓰지 않는다(기준일 표시, 취소 품목은 "현재 허가가 취소된 품목").

### 선택 구현(최종 구현 시까지 계속 검토)
1. `CHANGE_DATE`가 허가사항 전체의 마지막 변경일인지 식약처 명세로 확인 → 확인되면 "당시와 같음/다름" 판단 규칙 확정. (받은 9,987건 중 1,456건은 변경일 없음 → 확인 불가 처리)
2. 의약품안전나라 변경지시·(구)변경지시 메뉴의 데이터 제공 방식 확인 → 과거 허가사항 변경 이력의 출처로 쓸 수 있는지 판단.
