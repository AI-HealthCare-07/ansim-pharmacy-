## 제15조의6(복약지도서) 6항목 ↔ 데이터
1 명칭(성상) = item_name + chart / 2 용법·용량 = UD / 3 효능·효과 = EE / 4 부작용(상호작용·운전·기계조작 포함) = NB / 5 저장방법 = storage_method / 6 피해구제절차 안내 = 고정 문구(출처 확인 전 미운영)

## 원칙
- 근거 데이터 없는 항목은 "확인할 수 없어요". 추정·생성 금지. 약사가 최종 확인.
- 분류·성분은 법령·공식 코드로만 판단.

- 제86조의4제1항: 피해구제급여는 의약품안전관리원의 장에게 신청. 본법에는 별표 없음.
- 항목 6 문구는 `guidance_items.RELIEF_NOTICE_DRAFT`(약사 확인 전 미운영).
