## 3. 이슈 및 해결 (Troubleshooting)
- **OpenCV 소스 빌드**: Python 3.14용 `opencv-python-headless` wheel이 없어 소스 컴파일(16분 30초) 후 설치 성공
- **RapidOCR 한국어 미지원 오류**: 3.10 기본값(PP-OCRv6 small)에는 한국어 인식 모델이 없음 → `Rec.ocr_version=PPOCRV5`, `Rec.model_type=ModelType.MOBILE`(Enum으로 지정해야 함)로 해결
- **PDF 열기 실패(Operation not permitted)**: macOS가 터미널의 다운로드 폴더 접근을 차단 → 파일을 데스크탑으로 옮겨 해결
- **API 키 정리**: Console의 미사용 키 4개 삭제, `.env`의 키 1개만 유지(만료 2026-12-25, 12/20 전 갱신 필요)

- **실제 약봉투로 가림 시험**: 장식 글꼴 약국명이 깨져 읽힘(위치 기반 가림 추가), 건물·출구 표현 누락(보강). 받아 온 빈 약봉투 9장 전부 약국 정보 남지 않음 확인 (커밋 7220657)

## 4. 결정 사항
- 약 매칭 순서: EDI 코드 우선(쿠파린정 EDI 매칭 1.000 확인), 이름 검색은 EDI가 없을 때 사용
- 용량만 다른 제품(쎄레브렉스 100/200/400mg, 모두 0.9)은 동점 → 처방 용량으로 구분, 불가 시 사용자 확인
- RapidOCR 설정 고정: 글자 찾기 v6 small, 글자 읽기 한국어 v5 mobile
- 한국어 OCR 모델은 첫 실행 시 내려받음 → 배포(Docker) 시 이미지에 미리 포함 필요

- 약 자동 확인 규칙: 1등 0.7 이상 + 2등과 0.15 이상 차이, 수출용 제외. v2 평가(600종 2,139질의) 1등 정확도 91.9%, 자동 확인 61.1%, 정밀도 99.9%
- 남은 한계: OCR 오타가 다른 실제 약 이름이 되는 경우(자르탄정→자로탄정). EDI 우선, 확인 화면 성분명 표시로 대비
