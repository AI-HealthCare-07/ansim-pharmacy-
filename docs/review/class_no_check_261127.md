# 분류번호 별표 ↔ DB 대조 (2026-11-27, scripts/diag_class_table.py)

근거: 의약품등 분류번호에 관한 규정(식약처 예규 제223호, 시행 2026.2.23)의 별표 '의약품 분류표' → docs/ref/law_tables/class223_table.csv

- DB 저장 형식: 5자리 `0 + 분류번호 3자리 + 0` (예: 02140 = 214 혈압강하제). 5자리 형식 25,493건은 가운데 3자리가 모두 별표에 존재. 형식이 다른 것 94건.
- 번호·이름까지 일치 24,038건. 이름만 다른 1,455건(아래).
- 정상 품목 35,187건 중 분류번호 없음 13,628건(전체 20,718건은 취소·정지 포함). 허가 상세 API 응답에는 CLASS_NO 필드가 없어 이 공백은 이 경로로 채울 수 없다.

## 원칙
- 분류의 키는 번호. 이름은 별표 표기를 우선하고, 표기 차이는 정정하지 않고 둘 다 기록.
- 분류번호가 없는 13,628건은 이름·성분으로 추정해 채우지 않는다. 허가정보 목록 API에 분류번호 필드가 있는지 확인(미확인) 후 판단.
