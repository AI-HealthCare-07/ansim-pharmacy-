## 3. 이슈 및 해결 (Troubleshooting)
- **허가 상세 1,727건 비어 있음**: "최근 허가 품목이 API에 없다"는 추정은 틀렸음. 일일 한도 초과(429)였고, 스크립트가 이를 빈 응답으로 기록하던 결함도 고침(`fetch_permit_detail.py`: 429이면 멈추고 기록 안 함, `--retry-none` 추가)
- **주성분코드 없는 약의 원인 진단**
  - 확인됨: 458건(+1건)은 8~10월 급여목록에 있다가 11월 판에서 빠짐(10→11월 660코드가 한꺼번에 빠짐, 다른 달은 9~83개). 사유(삭제·제외·변경)는 파일에 없음
  - 배제: 정지 표시(정지 약은 목록에 남음), 앞자리 0 소실, 11/12 이후 신규 허가
  - 남은 1,682건: 원인 미확인. 이름에 "수출" 표기가 589건(35%, 주성분코드 있는 약은 7/20,676건)이지만 공식 근거는 미확인. 표기 없는 1,093건은 전혀 모름
  - 급여목록에는 있으나 우리 약 데이터에 이어지지 않는 EDI 96개(이름으로 짝짓지 않음)
  - 문서: `docs/review/nocode_diagnosis_261127.md`
- **`map_hira_edi.py` 사용 금지**: 열 선택 오류와 수정시각 기준 파일 선택(이전 판 파일이 들어와 잘못된 판을 고를 위험)
- **psql 없음**: `docker exec -i postgres psql ...`로 패치 적용
- **심평원 사이트 접속 불가**: 내장 브라우저에서 메인·조회 화면 3개 주소 모두 로딩되지 않음 → 표본 조회는 직접 해야 함
- **DUR 연결 증가분 분리 안 됨**: DUR 행에 품목이 있는 약 717 → 4,218건은 내려받기 진행분과 교정 효과가 섞임

## 4. 결정 사항
- 분류·성분 판단은 약사법, 대한민국약전, 분류번호 규정, 공식 코드의 정확 일치로만 함. 이름·성분 유사 추정 금지. 근거 없으면 "확인할 수 없어요"
- 서비스 전제는 의약분업: 처방은 의사, 조제·복약지도는 약사. 진단·처방·용량 변경·복용 중단 질문은 처방한 의사에게 확인하도록 안내
- 기준일 모델: 처방일·조제일 저장, 조제일 기준 법령·허가사항 적용(처방전 사용기간 조문은 미확인), 수집일 기준 이력 저장은 오늘부터 적용. `CHANGE_DATE` 의미와 변경지시 이력은 선택 구현으로 계속 검토
- 범위 밖: 임상시험 승인 자료, KPIS 일련번호·낱알식별
- 이전 판 급여목록에서 가져온 성분은 "급여목록 {판} 기준"으로 표시하고 급여 여부는 말하지 않음(약사 확인 필요)
- 교정·채움은 확정하지 않음. 교정만의 효과를 백업 테이블과 비교한 뒤 결정
